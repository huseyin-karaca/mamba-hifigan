# Caption (hero2)
**Inside every HiFi-GAN upsampling stage, a bidirectional Mamba branch with whole-utterance context runs beside the multi-receptive-field convolutions, and one learned scalar per stage mixes the two.**
A text-to-speech front end produces a mel spectrogram (shown: a real LJSpeech utterance, 80 mel bands, hop 256); the HiFi-GAN generator turns it into a waveform (shown: the gated model's output for the same utterance) through four upsampling stages (×8, ×8, ×2, ×2), each with its own gate α₁…α₄.
Zoom, one stage: the stage takes the gated output of stage i − 1 (for stage 1, the input convolution of the mel), upsamples it with its own transposed convolution, and hands the result x to both branches, which share no layers and run in parallel. The two branches are drawn mirrored about x on the same time columns (schematic, not to scale), so both outputs meet the gate from either side. BiMamba scans it forward and backward; the shade along each lane shows how much of the sequence that scan's state has absorbed, so the two sum to the whole sequence at every frame. At frame t the two states are added and layer-normalised. MRF runs three residual blocks with kernels 3, 7 and 11 (dilations 1, 3, 5) and averages them; each funnel is that block's receptive field at each of its six layers (25, 73 and 121 frames at the input, a vanishing fraction of an utterance at this resolution). The gate scales BiMamba by α_i = σ(w_i) and MRF by 1 − α_i; w_i starts at 0, an even split, and training moves it.
